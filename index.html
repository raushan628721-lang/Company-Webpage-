Corporate Employee & Admin System

Enterprise role-based portal with conditional access control and phpMyAdmin database authentication.

Portal Login ↗ New Registration
🎯 Specific Lab Exercise Condition Implemented:

Condition 1: If an Employee logs in, the portal authenticates the user and displays all Admin details.

Condition 2: If an Admin logs in, the portal authenticates the user and displays all Employee details.

⚡ PHP & MySQL Backend Config

This enterprise portal connects with Apache and MySQL on XAMPP using PHP PDO.

Database Setup:
Database: company_portal
Table: users (id, name, email, password, role, department, title, phone)
